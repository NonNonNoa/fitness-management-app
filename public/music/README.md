# 音楽ファイルの配置

## 使用方法

1. phonk音楽ファイル（MP3、WAV、OGG形式）をこのフォルダに配置してください
2. ファイル名を `phonk.mp3` にリネームしてください
3. または、`components/ui/music-player.tsx` の `src` プロパティを変更してください

## 推奨ファイル形式

- **MP3**: 最も互換性が高い
- **WAV**: 高音質だがファイルサイズが大きい
- **OGG**: ファイルサイズが小さい

## 注意事項

- 著作権に注意してください。自分で作成した音楽、または使用許可のある音楽のみを使用してください
- ファイルサイズが大きい場合、読み込みに時間がかかる場合があります
- 音楽ファイルは自動再生されません（ブラウザのポリシーにより、ユーザー操作後に再生されます）
