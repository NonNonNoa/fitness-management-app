## メモ・参考資料

### 技術的なメモ
- **MCP Server**: Turso Cloud MCP Serverを使用してデータベース操作が可能
- **認証フロー**: BetterAuth + Google OAuth、セッション管理はDBベース
- **Server Actions**: `"use server"`ディレクティブのファイルにはasync関数のみ配置
- **ヘルパー関数**: `lib/utils/`ディレクトリに分離（meal-helpers, workout-helpers, goal-helpers）

### 設計変更履歴
- 2024-12-21: BetterAuthスキーマに`id_token`, `access_token_expires_at`, `refresh_token_expires_at`を追加
